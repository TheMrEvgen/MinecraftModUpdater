# Список изменений

## Следующая версия

### Новое
- Обновление готовой сборки из каталога: при открытии программа сама замечает новую версию сборки и предлагает
  обновиться (или «Обновить сборку из каталога…» в меню сборки). Меняются только файлы самой сборки: моды,
  добавленные вами, и настройки, которые вы меняли, остаются; выключенный мод сборки остаётся выключенным.
  Для Prism Launcher заодно меняются версии Minecraft и загрузчика. Обновление можно отменить, а если хоть один
  файл не скачался — сборка остаётся прежней.
- Официальный Minecraft Launcher наравне с Prism: каждая его установка с модами (своя папка игры, версия) —
  отдельная сборка в списке. Для Fabric и Quilt программа сама ставит загрузчик и меняет версию установки:
  обновление загрузчика одной кнопкой, переход на новую версию Minecraft, готовые сборки из каталога — новой
  установкой в Minecraft Launcher. «Играть» открывает лаунчер сразу с нужной установкой.
- Загрузки как в Steam: индикатор внизу боковой панели (процент, скорость, сколько осталось) виден на любой
  странице, щелчок открывает страницу «Загрузки» — общий прогресс, график скорости, время до конца и каждый файл
  со своим прогрессом; загрузку можно отменить. Там же — обновления модов.
- Готовые сборки ставятся и обновляются в фоне: окно закрывается сразу, программой можно пользоваться дальше.
  Моды сборки качаются по четыре сразу.
- «Загрузки»: пауза и «Продолжить» (файл докачивается с того же места), при обрыве связи файл тоже докачивается
  сам; «Повторить неудавшиеся» — скачать только то, что не скачалось; несколько сборок качаются по очереди, а не
  делят скорость, порядок очереди можно менять («Раньше» / «Позже»).
- Уведомление Windows, когда сборка установлена или моды обновлены, а окно свёрнуто или в трее; щелчок открывает
  сборку.
- «Что нового» в окне обновления сборки: изменения всех выпусков между вашей версией и новой.
- Зависимость больше не считается недостающей, если мод стоит, но опознан в другом каталоге или не опознан вовсе
  (сверяются название и id мода внутри jar) — в готовых сборках пропадают ложные «проблемы». Для остальных случаев
  в меню зависимости есть «Не нужен — сборка работает без него».
- Щелчок по значку в трее убирает окно, если оно уже открыто.
- Java и память. Перед «Играть» программа проверяет, подходит ли Java версии игры (1.20.5+ — Java 21, 26.x —
  Java 25, старый Forge — Java 8) и хватит ли памяти на столько модов, и предлагает исправить: в Prism Launcher,
  MultiMC и официальном лаунчере — прямо в их настройках, с отменой. Разбор вылета распознаёт «не та Java» и
  «не хватило памяти» и говорит, что моды тут ни при чём, — с кнопкой исправления.
- Проверка модов на вирусы: признаки червя fractureiser (в том числе адреса, спрятанные в коде) и следы заражения
  компьютера. Моды проверяются в фоне при открытии сборки (повторно — только изменившиеся), вручную — «Если игра
  не запускается → Проверить моды на вирусы». Опасный мод убирается в бэкап одной кнопкой.
- Моды с GitHub: мод, которого нет ни на Modrinth, ни на CurseForge, связывается с репозиторием — сам, по ссылке
  на исходники внутри мода (если установленный файл есть среди выпусков), или вручную: «Указать страницу на
  GitHub…» в меню мода. Дальше он обновляется как остальные: нужный файл выпуска подбирается по версии игры и
  загрузчику, скачанное сверяется по SHA-256.
- Старый загрузчик. Новые версии модов часто требуют загрузчик новее (Sodium Extra 0.9.6 — Fabric Loader 0.20.1):
  программа читает это требование из самих модов и сразу после обновления, при открытии сборки и перед «Играть»
  предлагает «Обновить загрузчик». Разбор вылета распознаёт «нужна версия загрузчика новее» (Fabric, Quilt, Forge,
  NeoForge) и вместо «выключите моды» предлагает обновить загрузчик до нужной версии.
- Перевод описаний модов и списков изменений на язык интерфейса: кнопка «Перевести» / «Показать оригинал» в
  карточке мода, в каталоге и в окне «Что нового»; в настройках можно включить автоматический перевод. Разметка,
  ссылки и код сохраняются, переводы запоминаются.
- Новый язык интерфейса — один файл в `locales/`: программа сама находит его и показывает в настройках;
  `tools/i18n_check.py --template <код>` делает заготовку со всеми строками.
- Сборка для сервера (.zip): моды без «только для клиента» (список можно поправить), настройки модов и всё для
  запуска — для Fabric готовый серверный файл и start.bat/start.sh, для Forge и NeoForge установщик сервера.

### Исправления
- Экспорт в .mrpack больше не замораживает окно, пока узнаёт версию загрузчика.
- Проверка версии загрузчика читает моды в фоне и запоминает результат — без пауз на больших сборках.
- Установки Forge старого формата (например, 1.8.9-forge1.8.9-11.15.1.2318) не распознавались как Forge.
- Уведомления и панель выделения больше не закрывают нижние строки списка модов.
- В журнале «Найдено обновление» для мода-зависимости писалось по разу на каждый зависящий от него мод.
- Вкладка каталога «Сборки»: свой подзаголовок, без фильтров, которые к сборкам не относятся.

## 3.6.1-beta — 2026-10-24

### Исправления
- Программа могла внезапно закрыться после проверки обновлений («QThread: Destroyed while thread is still running»):
  фоновые задачи теперь живут до полного завершения.

## 3.6.0-beta — 2026-10-24

### Новое
- Готовые сборки в каталоге (вкладка «Сборки», Modrinth и CurseForge): установка одной кнопкой — моды, настройки
  модов, ресурспаки и шейдеры. Если есть Prism Launcher, создаётся новая сборка с нужными версиями Minecraft,
  загрузчика и LWJGL — «Играть» работает сразу; иначе — в папку на диске.
- Legacy Launcher (legacylauncher.ru): его папка игры и выбранная версия находятся автоматически, «Играть» открывает лаунчер.

## 3.5.0-beta — 2026-10-24

### Новое
- Сборки Prism Launcher и MultiMC: загрузчик обновляется щелчком по его плашке, а при переходе на новую версию
  Minecraft программа меняет версию игры, загрузчика и LWJGL прямо в сборке лаунчера (по справочнику Prism).
  Файл сборки сохраняется — изменение можно отменить из уведомления.
- «Моды во всех сборках» (меню «⋯» и Ctrl+K): в каких сборках стоит мод и какой версии.
- Там же — экономия места по желанию: одинаковые файлы модов в разных сборках можно хранить на диске один раз
  (жёсткие ссылки). Только по кнопке и после подтверждения; обновление в одной сборке другие не затрагивает.
- Один и тот же мод из двух каталогов (Modrinth и CurseForge) помечается как проблема — с такими дублями игра падает.

## 3.4.0-beta — 2026-10-24

### Новое
- Мастер первого запуска: язык и тема, найденные сборки, установка программы.
- Настройки: колонка разделов с переходом и поиск по настройкам.
- Компактные счётчики-фильтры над списком модов — в список помещается больше строк.
- Боковую панель можно свернуть до значков; в узком окне она сворачивается сама.
- Датапаки — четвёртая вкладка: у каждого мира свои (выбор мира рядом с версией игры), проверка обновлений,
  каталог Modrinth и CurseForge. Миры программа не трогает — только их папку datapacks.
- Импорт сборок CurseForge (`.zip` с `manifest.json`): через «Открыть сборку» или перетаскиванием в окно.
- Отложенные обновления: «Ставить новые версии не раньше чем через 1–14 дней». Слишком свежие версии видны
  с пометкой «ждёт N дн.», но не попадают в «Обновить все», фоновые уведомления и `--update-all`.
- Недостающие обязательные зависимости модов с CurseForge. Зависимость, установленная с любого каталога
  (например, Fabric API с Modrinth), считается установленной.

### Исправления
- Экспорт `.mrpack`: моды не с Modrinth больше не попадают в файл с недопустимыми ссылками — программа называет их.

## 3.3.0-beta — 2026-10-23

### Новое
- CurseForge — второй источник модов:
  - моды, которых нет на Modrinth, опознаются по отпечатку файла на CurseForge: название, иконка, страница,
    проверка и установка обновлений, «Что нового», готовность к новой версии игры;
  - в каталоге переключатель «Modrinth / CurseForge»: поиск, категории, страница проекта с версиями и скриншотами,
    установка с обязательными зависимостями;
  - если автор запретил скачивание сторонними программами, программа показывает новую версию и открывает
    страницу файла на сайте — скачать его можно там.
- Моды, которых нет ни на Modrinth, ни на CurseForge, — в группе «Нет в каталогах».

### Исправления
- Иконки модов с CurseForge сохраняются в кэш (имя файла без двоеточия).

## 3.0.0-beta — 2026-10-23

Полностью новая версия: новый интерфейс и много новых возможностей.

### Интерфейс
- Боковая панель сборок, список модов с панелью подробностей, вкладки модов, шейдеров и ресурспаков.
- Режимы списка: все моды с зависимостями, только мои моды, дерево зависимостей; выбор колонок, компактные строки.
  На широком экране размер, дата и сторона — отдельными колонками.
- Темы: системная, тёмная, светлая, OLED, высококонтрастная; цвет акцента, масштаб, картинка в боковой панели.
- Английский язык интерфейса (выбор в настройках), включая журнал. Даты в формате языка.
- Палитра команд Ctrl+K, свои горячие клавиши, режим «Минимум», Ctrl+Z для последних действий.
- Окно при сбое программы с отчётом; один экземпляр программы.

### Обновления и сборки
- Каталог Modrinth: фильтры, страница проекта со скриншотами, отметки и массовая установка.
- «Что нового» перед обновлением, закрепление версий, выключение модов без удаления.
- Снимки сборки и история операций с откатом.
- Переход сборки на другую версию Minecraft и проверка готовности модов к новой версии.
- Поиск с условиями, избранное, заметки, метки, группы и наборы модов, статистика сборки.
- Клонирование и сравнение сборок, перенос настроек на другой компьютер.
- Установка из самой программы: ярлыки, удаление через Windows, `.mrpack` двойным щелчком, ссылки `modupdater://`.

### Игра
- Кнопка «Играть», наблюдение за игрой и блокировка изменений модов, пока она запущена.
- Разбор вылета (краш-репорт и лог) — автоматически после вылета.
- Поиск проблемного мода перебором: вручную или полностью автоматически.

### Исправления
- Зависимости другого загрузчика (Fabric API у мультизагрузочного мода на NeoForge) больше не считаются обязательными.
- Закрытие окна не зависает, если Modrinth отвечает медленно.
- «Выбрать все», стрелки выпадающих списков, кнопки пустого состояния, совпадающие папки операций.
